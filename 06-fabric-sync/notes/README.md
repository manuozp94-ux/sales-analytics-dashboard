# Fabric Change Notes

Use this directory to store one short note per major Fabric change.

## Required Trigger

Create a note after changes to:

- pipelines,
- warehouse schema/core model,
- marts,
- semantic model,
- security/governance settings.

## Required Evidence

Each note must include:

1. Fabric inventory diff reference.
2. Snapshot file reference.
3. Links to impacted local artifacts (SQL/docs/notebooks).

Start from `FABRIC_CHANGE_NOTE_TEMPLATE.md`.
