# Context Consolidation Archive

This directory stores historical conversation-derived artifacts kept for traceability.

## Usage Policy

- Treat this directory as **archive-only**.
- Do not use archive files as canonical governance sources.
- For current operational decisions, use:
  - `05-docs/PROJECT_RULES.md`
  - `05-docs/ROADMAP.md`
  - `05-docs/project-memory/*`

## Language Policy

- Canonical project documentation remains English-only.
- Archive content may contain legacy bilingual material from prior sessions.
