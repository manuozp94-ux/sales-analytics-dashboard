OBJETIVO PRINCIPAL

Construir un proyecto técnico de ingeniería analítica que permita aprender y demostrar competencias en:

- preparación de datos
- modelado analítico
- arquitectura de datos
- herramientas modernas de analytics engineering.

OBJETIVOS ESPECÍFICOS

1. Aprender uso básico de terminal (zsh).
2. Configurar entorno Python.
3. Trabajar con pandas para validación de datos.
4. Diseñar modelo dimensional (star schema).
5. Implementar SQL analítico.
6. Comprender arquitectura compatible con Microsoft Fabric.

NO OBJETIVOS (según conversación actual)

No se mencionó intención de:

- construir dashboards finales
- publicar reports
- implementar pipelines productivos
- optimización de performance
- gestión de infraestructura cloud real.

SUPUESTOS

- Los datos iniciales estarán en CSV.
- El trabajo comenzará con exploración en Python.
- El modelado analítico se hará después de validar datos.

RESTRICCIONES

- aprendizaje progresivo
- desconocimiento parcial de Python
- trabajo paso a paso
- dataset aún no definido.
