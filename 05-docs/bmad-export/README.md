# BMAD Export Package

This folder converts the repository’s Fabric implementation history into a reusable planning and legacy package.

## Purpose

Use this package when you need to:

- understand what was actually implemented in Fabric and Azure DevOps,
- preserve the most valuable lessons from this repository,
- translate technical history into Product Brief-ready input,
- position this repo as a strong portfolio artifact instead of a raw implementation log,
- prepare the next repository to start from architecture, contracts, and agent-assisted planning.
