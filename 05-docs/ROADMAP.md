# Career Roadmap (Canonical)

Role strategy: **Analytics Engineer first**, with clear Data Analyst outcomes for hiring evidence.

## Timeline Overview

- Portfolio MVP target: **4 weeks**
- Job application start: **Week 2**
- Certification sprint: **8-10 weeks** (PL-300 then DP-600)

## Week 1 — Foundation Hardening

- Repository governance and workflow standards in place.
- Project memory subsystem fully operational.
- Canonical English documentation established.
- CI baseline active for SQL checks, notebook sanity checks, and doc link checks.

### Exit Criteria

- New contributor can find how to resume work and how to contribute.
- Quality checks run successfully in CI.

## Week 2 — First Public Portfolio Release

- Publish first Power BI dashboard iteration sourced from gold outputs.
- Publish architecture narrative (local DuckDB path + Fabric translation).
- Publish first case study draft.
- Start job applications with initial evidence package.

### Exit Criteria

- Public artifacts available in GitHub portfolio context.
- Application-ready summary links are prepared.

## Week 3 — Hiring Narrative Strengthening

- Improve business impact narrative for US hiring audience.
- Tighten metric contract traceability from source to dashboard.
- Add explicit QA evidence and data quality narrative.

### Exit Criteria

- Case study demonstrates technical depth + business communication clarity.

## Week 4 — MVP Finalization

- Recruiter-friendly README and navigation polish.
- Reproducibility checklist finalized.
- GitHub Pages case study path finalized.
- Weekly milestone tag created and documented.

### Exit Criteria

- Public repo + case study + working dashboard link available.

## Certification Plan (8-10 Weeks, Aggressive)

## Track A — PL-300 (First)

- Weekly focus:
  - data modeling and transformation,
  - DAX and report design,
  - performance and deployment practices.
- Weekly checkpoint:
  - practice score,
  - weak domains,
  - exam booking status.

## Track B — DP-600 (Second)

- Weekly focus:
  - Fabric architecture and workloads,
  - Lakehouse/Warehouse patterns,
  - governance and performance.
- Weekly checkpoint:
  - practice score,
  - weak domains,
  - exam booking status.

## Delivery Cadence and Milestones

- Weekly tag format: `portfolio-week-XX`
- Each tag summary should include:
  - portfolio artifacts released,
  - engineering upgrades made,
  - certification progress snapshot.
